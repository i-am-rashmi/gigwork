# GigWork

Hirers post local gigs; Doers subscribed to that category and city are notified
within seconds, apply, and the Hirer selects. Built to explore three backend
problems: reliable fan-out, geo search at scale, and concurrent state transitions.

**Status:** design complete · core APIs in progress · [live demo](#) · [design docs](docs/)

## Data attribution

Reference seed data (zones and localities) in `infra/seed/` is derived from OpenStreetMap contributors (ODbL), OpenCity (ODbL) and India Post via data.gov.in (GODL). Sources, licences and how it is generated: [tools/locality-import/README.md](tools/locality-import/README.md).
