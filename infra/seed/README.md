# Seed data

Reference data per city, generated by [`tools/locality-import`](../../tools/locality-import/README.md). Do not edit by hand; regenerate with the tool.

| File | Content |
|---|---|
| `<city>/zones.geojson` | Zone boundaries (simplified), property `name` only |
| `<city>/localities.csv` | `name,pin,lat,lng`: search shortcuts for "type your area or PIN" (`pin` may be empty) |

## Notes for the loader

- **Names are not unique per city.** The same locality name can appear more than once (different places more than 1 km apart, sometimes with different PINs). Do not add a unique constraint on name and do not look localities up by name alone.
- `pin` may be empty.
