# Glossary

- **Talent**: a user offering a service (photographer, mehendi artist, etc.). A talent profile is an add-on to an account, not a separate account type.
- **Poster**: a user who publishes a gig. Any account can be a Poster.
- **Gig**: a single piece of work with a category, time window, location and budget.
- **Gig group**: several gigs created together from one AI drafting request.
